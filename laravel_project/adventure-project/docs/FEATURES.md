# AdventureX Features

## Core Features

- Responsive mobile UI with dark mode
- Adventure listing with advanced filtering and sorting
- User dashboard and booking management
- Secure payment processing
- PDF invoice generation and email receipts
- Real-time notifications
- Multi-image gallery with cover image support
- Adventure scheduling and seat management
- Admin dashboard with revenue and booking analytics
- Staff role management

## Technical Features

- Laravel 12 with Inertia.js and Vue 3
- REST API powered by Laravel Sanctum
- Queue-based async jobs (emails, invoices)
- Daily automated database backups
- Localization in English
- Form request validation
- Authorization policies
- Automated feature tests
- Optimized for production with Nginx, Supervisor, and Scheduler
